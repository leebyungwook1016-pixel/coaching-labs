# 1회차 전문가 멘토링 신청 (2026-11-17)

- **진행 단계**: 기획
- **멘토링 분야**: 기획 / 비대면

## 현재 진행 상황
- 기본정보 입력 → 맞춤형 8주 훈련 프로그램 생성·출력 핵심 기능의 기초 구현과 작동 확인 완료
- 파워미터 사용자용 FTP·IF·TSS 기반 훈련 알고리즘 구성
- 파워미터가 없는 사용자용 심박수(카보넨 공식) + RPE 기반 8주 주기화 프로그램 구성
- 춘천 관광명소·안전 자전거 도로 추천 기능 구상 중

## 고민 (애로사항)
전문 지표 기반 기능과 일반 동호인용 보편 기능(심박수 훈련, 춘천 코스 추천)을 모두 담으면 서비스 정체성이 흐려지고 앱이 무거워질 수 있음. 공모전 취지(지역사회 문제 해결)에 맞춰 어느 쪽에 집중할지 우선순위 결정이 필요.

## 멘토에게 한 질문
1. 초기 시제품에서 파워미터 기능을 빼고 **일반 사용자 맞춤 훈련 + 춘천 안전 코스·관광명소**에 집중할까, 아니면 처음에 파워미터 유무를 물어 **두 그룹 모두** 지원할까?
2. 지도에 **춘천 관광명소**를 담을까, **시내 카페·맛집**을 소개해 로컬 경제 활성화에 집중할까?
3. 5만 원대 블루투스 심박계와 연동해 **실시간 세션 추적·데이터 분석**을 넣는 것은 구현 가능할까?
