# 개발 계획 요약

> 2026-10-18 제출한 개발 계획서를 요약한 문서입니다. (개인정보 제외)

## 개요
사이클 동호인의 신체 정보, 훈련 수준, 훈련 가능 시간과 목표에 맞는 **8주 단위 맞춤형 훈련 프로그램**을 AI로 자동 생성하는 서비스.

## 입력 정보
- 나이, 체중, FTP, 훈련 경력
- 주당 훈련 가능 시간 및 횟수
- 훈련 목적: 입문·기초 체력 향상 / 중급·상급 기량 향상 / 대회 준비

## 출력 결과
- 주차별 훈련 방향과 목표
- 세션별 운동 목적, 권장 강도, 훈련 시간, 인터벌 구성
- 강도와 휴식 구간을 보여주는 도식
- FTP 기준 상대 강도(IF), 훈련량(TSS) 반영

## 차별성
기존 훈련 분석 도구가 **측정된 데이터를 보여주는 데** 초점을 둔다면, 이 서비스는 사용자의 현재 조건과 목표로 **실제 훈련 계획을 만들어 주는 데** 초점을 둔다. 복잡한 훈련 원리를 사용자가 직접 적용할 부담을 줄이고, 입력부터 결과 확인까지 간단한 화면으로 연결한다.

## 배경
- 춘천 지역 사이클 트레이닝 현장에서, 동호인들이 파워미터를 쓰면서도 측정값을 훈련 계획으로 연결하지 못하는 사례를 반복적으로 확인
- 전문가 지식을 사용자 친화적으로 담은 서비스가 있으면 지역 생활체육의 접근성과 지속적인 운동 참여를 높일 수 있음

## 기대 효과
1. 동호인의 훈련 접근성과 자기주도적 운동 역량 향상
2. 파워미터 지표(FTP, TSS 등)의 실질적 활용 확대
3. 무리한 훈련을 줄이고 회복의 중요성을 이해하는 건강한 운동 습관
4. 춘천 지역 생활체육 현장에 쓸 수 있는 디지털 서비스 기반 마련
5. 향후 실제 주행 데이터 연동, 계획 대비 수행 비교, 코치용 관리 도구로 확장 검토
